## 專案簡介

本專案使用 ASP.NET Core MVC 開發，建立一個具備會員管理、角色權限管理及商品管理功能的線上購物網站後台。

## 使用技術

- **程式語言：** C#
- **後端框架：** ASP.NET Core MVC
- **資料庫：** Microsoft SQL Server
- **ORM：** Entity Framework Core
- **會員驗證：** ASP.NET Core Identity
- **開發工具：** Visual Studio

## 專案功能

1. **會員管理：** 建立會員資料及管理會員資訊。
2. **身分驗證：** 整合 ASP.NET Core Identity，處理會員註冊與登入。
3. **角色管理：** 建立、查詢及管理使用者角色，作為權限控管的基礎。
4. **商品管理：** 建立商品資料的新增、查詢、修改及刪除功能。
